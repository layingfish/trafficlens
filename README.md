# TrafficLens 智能流量分析平台

**在线演示：<https://layingfish.github.io/trafficlens/>**（浏览器直接打开，无需安装）

基于 Telecom Italia（米兰 / 特伦蒂诺）与 ZTE（济南 4G 下行）区域级移动流量数据的 Web 应用，
覆盖 **探索性分析 → 功能区聚类 → 预测数据构建 → 18 种预测算法训练（实时监控） → 预测展示与评估** 的完整流程。

## 在线演示

<https://layingfish.github.io/trafficlens/>：静态只读版，托管在 GitHub Pages，包含米兰和特伦蒂诺两个数据集。
所有结果都由 `tools/build_static.py` 在本机预先算好，写入 `docs/`，所以静态版和本机版有几处不同：

- 探索分析的时间序列只提供 1h、2h、4h、1D 四种粒度
- 聚类参数只能在预先算好的网格中选择，例如 k 取 2 至 8
- 不能构建数据集、训练模型，也不能导出全部预测 CSV

更新在线版的步骤：本机重新训练后运行 `python tools/build_static.py`，然后提交 `docs/` 并推送。

## 快速开始

```bash
pip install -r requirements.txt     # 已有 anaconda 环境可跳过
python app.py                       # 或 ./run.sh
# 浏览器打开 http://127.0.0.1:8000
```

前端库（ECharts 5.5.1、Leaflet 1.9.4）已放在 `static/vendor/`，无需联网即可使用；只有地图底图瓦片需要联网（离线时区域多边形照常显示）。

## 数据（`data/`）

| 数据集 | 区域 | 原始粒度 | 时间范围 | 地理文件 |
|---|---|---|---|---|
| 米兰 Milano | 88 个 NIL 街区 | 10 min | 2013-11-01 → 2014-01-01 | `milano.geojson` |
| 特伦蒂诺 Trentino | 223 个市镇 | 10 min | 2013-11-01 → 2014-01-01 | `trento.geojson` |
| 济南 ZTE 4G 下行 | 148 个街道 | 15 min | 2024-07-28 → 2024-08-25 | `zte_4g_down.traffic.geojson` |

本仓库只公开意大利两份数据。它们来自 Telecom Italia Big Data Challenge（Barlacchi et al., *Scientific Data* 2015），以 ODbL 许可发布。济南数据不在仓库中，需要单独放进 `data/`。

CSV 每列是一个区域，列名与 GeoJSON 中的区域键（`NIL` / `NAME_3` / `unique_id`）一一对应。重采样时按求和聚合。
意大利法定节假日（11-01、12-08、12-25、12-26、01-01，米兰另含 12-07 圣安布罗斯节）与周末一起视为「休息日」。

## 功能与课程要求对照

### 1）探索性分析：时间动态 + 空间动态
- **整体**：全网小时流量曲线（可缩放）、日总量柱状图（休息日高亮）、KPI 卡片
- **时间动态**（可选最多 5 个区域、可切换粒度）：区域时间序列；工作日 vs 休息日日内曲线；星期×小时热力图；分时段箱线图；ACF 自相关（0–14 天）；MSTL 多季节分解（趋势 + 日周期 + 周周期 + 残差）；每日总量
- **空间动态**：
  - 分级设色地图：平均流量 / CV / 峰值时刻 / 休工比 / 夜间占比 / 昼夜比
  - **典型日 24 小时动画**（工作日/休息日）与**逐日演变动画**，色阶可选全局统一或逐帧
  - 全局 Moran's I 随小时、随日期的变化（kNN 空间权重）
  - LISA 局部空间自相关聚类图（HH/LL/HL/LH，置换检验 p<0.05）
  - 区域对「时间序列相关系数—质心距离」衰减散点
  - 区域统计排行表（可排序，点击加入时间分析；地图上点击区域同理）

### 2）聚类：功能区发现
- 特征：工作日+休息日日内曲线(48 维) / 平均日内曲线(24) / 周内曲线(168) / 统计特征
- 归一化：形状归一（除以均值）/ Z-score / log1p 原值
- 算法：K-Means、层次聚类、GMM、谱聚类、DBSCAN、HDBSCAN（参数均可调）
- 输出：功能区地图、各簇工作日/休息日/周内中心曲线、PCA 或 t-SNE 二维嵌入、轮廓系数 / CH / DB 指标、肘部法则选 k
- **功能区解释**：对每个簇计算工作时段指数、晚间指数、夜间指数、休工比、量级、振幅，相对其他簇做 z 分数，
  自动命名为 商务办公区 / 居住区 / 休闲商业·旅游区 / 低活跃·郊野区 / 混合功能区（命名规则见 `core/cluster.py: interpret`）
- 聚类结果可直接在「预测数据构建」中按簇选择区域

### 3）预测数据构建面板
- 区域范围：全部 / 流量最高 N 个 / 某个聚类簇 / 手动多选
- 时间粒度（原始、30min、1h、2h、4h、1D）、**输入长度 L、输出长度 H 手动设定**（附常用预设与时长换算）
- 训练/验证比例、窗口步幅、归一化方式（Z-score / Min-Max / 无，仅用训练段拟合）、可选 log1p
- 展示：张量形状 `X:[样本, L, N] → Y:[样本, H, N]`、各集合时间范围与窗口数、时间切分预览图、样本窗口示意图
- 按时间顺序切分：验证/测试窗口的**目标**完全落在各自时间段内，输入可回看之前的已观测历史

### 4）预测算法面板（18 种，参数均可调，训练实时监控）

| 类别 | 算法 | 主要可调参数 |
|---|---|---|
| 统计 | 历史平均 HA | 周期(日/周)、回看周期数 |
| 统计 | 季节朴素 | 季节长度(last/日/周) |
| 统计 | ARIMA | p, d, q、拟合长度、最大迭代 |
| 统计 | Holt-Winters | 季节周期、α/β/γ、趋势项、自动优化 |
| 机器学习 | Ridge 线性回归 | α、截距 |
| 机器学习 | KNN | K、权重、距离度量 |
| 机器学习 | SVR | 核函数、C、ε、γ |
| 机器学习 | 随机森林 | 树数、深度、叶子样本、特征比例 |
| 机器学习 | LightGBM | 迭代数、学习率、叶子数、深度、采样率、λ、早停 |
| 深度学习 | MLP | 隐藏单元、层数、dropout、激活函数 |
| 深度学习 | LSTM | 隐藏单元、层数、dropout、双向 |
| 深度学习 | GRU | 同上 |
| 深度学习 | Seq2Seq | 隐藏单元、层数、teacher forcing 比例 |
| 深度学习 | TCN | 通道数、残差块层数、卷积核、dropout |
| 深度学习 | Transformer | d_model、头数、层数、前馈维度、dropout |
| 深度学习 | DLinear | 滑动平均窗口 |
| 深度学习 | N-BEATS | 块数、隐藏单元、每块层数 |
| 图神经网络 | T-GCN | 隐藏单元、层数、邻接图(距离 kNN / 相关性 kNN)、k |

所有深度模型共享：epochs、batch、学习率、权重衰减、优化器、损失函数(MSE/MAE/Huber)、学习率调度、早停耐心、梯度裁剪、每轮采样数、时间特征开关、设备(CPU/MPS/CUDA)、随机种子。
ML 模型共享：时间特征开关、最大训练样本数、随机种子。

**训练与监控**
- 可一次勾选多个算法提交，任务进入队列（默认 2 个并行槽位），每个任务在**独立子进程**中运行
- 浏览器通过 SSE 实时接收：进度条（epoch/batch、树数、迭代轮数、区域拟合进度）、训练/验证损失曲线、验证集 MAE（原始单位）、学习率、日志
- 可随时停止：深度学习 / 随机森林 / LightGBM 会保留当前最佳模型并完成测试评估
- 结果保存在 `results/`（`.json` 元信息 + `.npz` 预测数组），重启服务后仍可在评估页查看

### 5）预测展示与评估
- 模型排行榜（同一数据集下，按任一指标排序，最佳值加粗），勾选多个模型对比：指标柱状图、误差随预测步长变化曲线
- 单模型：MAE / RMSE / MAPE / sMAPE / WAPE / R²（测试集 + 验证集）、训练/推理耗时
- 测试期真实值 vs 预测值（任选区域或全部合计、任选预测步长 h）
- 单样本视图：历史输入 + 未来真实值 + 预测值（滑块切换样本）
- 预测 vs 真实散点（含 y=x 线）、残差分布直方图、分步长误差柱状图
- 误差最大的 15 个区域、分区域误差地图
- 导出：分区域指标 CSV、全部预测明细 CSV

指标均在**原始量纲**上计算；MAPE 排除真实值小于全局均值 1% 的点，避免除零放大。

## 目录结构

```
app.py               FastAPI 后端（REST + SSE）与静态页面
core/data.py         数据集注册、加载、重采样、质心/距离/邻接、Moran's I
core/eda.py          时间/空间动态分析（MSTL、ACF、LISA、距离衰减…）
core/cluster.py      聚类特征构建、6 种聚类算法、功能区解释
core/windows.py      滑动窗口预测数据集构建与切分
core/metrics.py      评估指标（总体 / 分步长 / 分区域）
core/models/         18 种算法：stats.py · ml.py · deep.py（共享训练循环）
core/trainer.py      任务队列、子进程训练、事件流、结果持久化
static/              前端（原生 JS + ECharts + Leaflet）
```

## 说明与注意

- 米兰/特伦蒂诺默认 7:1:2 切分时，测试集落在 12 月 20 日至元旦，包含圣诞假期——流量模式与训练期明显不同，
  依赖长期周期的方法（如按周的历史平均）在该段误差会偏大，这本身是一个值得在报告中讨论的现象。
- 特伦蒂诺 10 分钟原始粒度 × 223 区域时样本量很大，建议使用 1h 粒度，或在深度模型中设置「每轮最多样本」。
- SVR 为核方法，复杂度随样本平方增长，默认只用 4000 个训练样本。
